# EduSense Website
Responsive landing page for **EduSense**, the AI-powered gesture-control slide remote.

- **Demo**: https://github.com/OkwirFrances/edusense_websites  
- **Template**: Based on [yenchiah/project-website-template](https://github.com/yenchiah/project-website-template)

### Quick Edit Map
- `index.html` – Main marketing page  
- `privacy.html` – Privacy policy (built from `empty.html`)  
- `widgets.html` – Interactive demos (dialogs, photo picker)  
- `embedding.html` – Full-screen demo video  
- `menu.html` & `footer.html` – Re-usable nav & footer  
- `img/` – Replace all `dummay-img.png` with EduSense screenshots & badges
